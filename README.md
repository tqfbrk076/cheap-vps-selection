## 这笔钱买到了什么

**KVM 虚拟化、独立 IPv4、1Gbps 端口。** 官方特价页写明每个方案都带完整 root 权限和 1Gbps 端口，官方套餐页也确认每个方案含一个 IPv4 地址。1Gbps 是端口速率，不是给你跑满的保障带宽，实际能跑多少取决于机型和同时段负载。

**一个叫 ctrl 的控制面板。** 官方说明里，ctrl 随每个特价 VPS 提供，能做的事包括重启、重装系统、打开 HTML5 VNC 控制台、装一键应用、用面板自带的网络防火墙设入站规则、重置 root 密码、升配。系统可选 CentOS、Rocky Linux、AlmaLinux、Fedora、Debian、Ubuntu，要自定义 ISO 可以开工单。

**能自己装 Docker。** 有一键 Portainer，也可以 SSH 上去自己装。跑 WordPress 有 AdminBolt、CyberPanel、CloudPanel 这类一键应用，也可以完全自己搭。

**一份写得比较直白的 SLA。** 第三方对官方条款的梳理显示，网络和电力按月承诺 99.999%，超出部分每小时赔付月费的 2%，上限 50%，需要 30 天内邮件申请，每月 180 分钟以内的计划维护不算在内。这个数字看着漂亮，但真出事时赔的是月费比例，不是业务损失，别当成生产环境的保险。

**第一，没有中国优化线路。** 这是 RackNerd 和贵一档产品的分界线。第三方对它的定位描述是“适合对线路无特殊要求的国内外用户”，另一份横向对比说得更直接：这类年付十美元以内的商家，“IP 属性、线路质量、中文支持都不在一个档次上”。晚高峰绕路、延迟忽高忽低，是这类普通国际线路的固有表现，不是偶发故障。

## 年付锁定：第一年便宜，第二年呢

续费价是这类促销最容易被含糊带过的地方。第三方评测里出现了两种说法：一家引用 RackNerd 的 FAQ，说特价套餐是“lifetime recurring”，按同价续费；另一家 2026 年 9 月的评测则明确表示，促销页的续费措辞每次活动都可能不同，它无法替读者确认，建议直接看活动页上的 renewal 说明。两方说法不一致，我不替它们下结论。
